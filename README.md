# FraudShield — Setup Guide

## Project Structure

```
fraudshield/
│
├── app.py              ← Flask backend (run this)
├── train\_model.py      ← ML training script (run once)
├── requirements.txt
│
├── index.html          ← Login / Register page
├── app.html            ← Main dashboard  
│
├── css/
│   ├── theme.css
│   ├── app.css
│   └── landing.css
│
├── js/
│   └── app.js          ← Dashboard logic (connects to API)
│
└── model/
    ├── fraud\_model.pkl ← Generated by train\_model.py
    └── model\_info.json
```

\---

## Step 1 — Install Python dependencies

```bash
pip install -r requirements.txt
```

\---

## Step 2 — (Optional but recommended) Train the ML model

### With Kaggle dataset (best accuracy):

1. Go to https://www.kaggle.com/mlg-ulb/creditcardfraud
2. Download `creditcard.csv`
3. Place it in the `fraudshield/` folder
4. Run:

```bash
python train\_model.py
```

### Without the CSV (development mode):

Just run `train\_model.py` anyway — it generates synthetic data
and still saves a working model:

```bash
python train\_model.py
```

\---

## Step 3 — Start the Flask server

```bash
python app.py
```

Server starts at: **http://127.0.0.1:5000**

\---

## Step 4 — Open the app

Open **index.html** in your browser (double-click or use Live Server).

* Register a new account
* Log in
* The dashboard connects to Flask automatically

> \*\*Tip:\*\* Use VS Code Live Server extension or `python -m http.server 8080`
> to serve the HTML files — then open http://localhost:8080/index.html

\---

## How it works

|Layer|What happens|
|-|-|
|`index.html`|Login/Register — calls `/api/login` or `/api/register`|
|`app.html` + `js/app.js`|Dashboard — sends every transaction to `/api/analyze`|
|`app.py`|Scores transaction using ML model + rules, saves to SQLite|
|`fraudshield.db`|Stores users, transactions, alerts (auto-created)|
|`train\_model.py`|Trains Random Forest / Logistic Regression on Kaggle data|

\---

## API Endpoints

|Method|Endpoint|Description|
|-|-|-|
|POST|`/api/register`|Create account|
|POST|`/api/login`|Sign in|
|POST|`/api/logout`|Sign out|
|GET|`/api/me`|Get logged-in user profile|
|PUT|`/api/profile`|Update home location / avg spend|
|POST|`/api/analyze`|Analyze a transaction → returns fraud result|
|GET|`/api/transactions`|Get transaction history|
|GET|`/api/alerts`|Get alert history|
|GET|`/api/stats`|Get dashboard counters|

\---

## Troubleshooting

**CORS error in browser:**  
Make sure `flask-cors` is installed and Flask is running on port 5000.

**Model not found:**  
Run `python train\_model.py` first. The app works without it (rule-based fallback).

**Can't log in:**  
The SQLite database (`fraudshield.db`) is created automatically on first run of `app.py`.
